# Security Policy

## Supported Versions

We are committed to ensuring the security of the Flambo app. Because we are currently transitioning to a completely new architecture and UI, **security updates will only be provided for the 2.0 release branch and newer.**

Older versions (1.x.x and below) are no longer supported and will not receive security patches. We highly recommend all users upgrade to the latest version.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Flambo, please **do not** disclose it publicly through GitHub issues or public discussions. Instead, we ask that you report it privately so we can address it before it can be exploited.

**How to report:**
Please use GitHub's private vulnerability reporting feature:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click **Report a vulnerability** to submit your report securely.

*(Alternatively, you can email us directly at [Benmohamedm715@gmail.com])*

**What to include in your report:**
*   A detailed description of the vulnerability.
*   Steps to reproduce the issue.
*   The potential impact (e.g., data exposure, privilege escalation).
*   Any suggested fixes or mitigations (if applicable).

**What to expect from us:**
*   **Initial Response:** You can expect an acknowledgment of your report within **48 hours**.
*   **Updates:** We will provide updates on our progress at least once a week until the issue is resolved.
*   **Resolution:** If the vulnerability is accepted, we will work on a patch for the `2.0.x` branch as quickly as possible and coordinate a release. We will also credit you in the release notes (unless you prefer to remain anonymous).
*   **Declined Reports:** If the report is declined (e.g., it is not a security issue, or it affects only unsupported versions < 2.0), we will provide a clear explanation as to why.

We kindly ask that you give us reasonable time to address the vulnerability before making any public disclosures. 

Thank you for helping keep Flambo and its users safe!
